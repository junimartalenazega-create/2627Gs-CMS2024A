Ninis — Ruang Cerita Ninis

Deskripsi
Ninis adalah tema WordPress kustom yang dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS). Tema ini digunakan pada website Ruang Cerita Ninis, sebuah website blog pribadi dengan tampilan sederhana, menarik, dan bernuansa pastel.
Tema ini dikembangkan menggunakan HTML, CSS, PHP, serta fungsi bawaan WordPress. Desainnya menggunakan perpaduan warna pastel dan ilustrasi dekoratif untuk menciptakan tampilan blog yang nyaman dibaca.

Fitur Utama
- Homepage: Menampilkan halaman utama website dan artikel terbaru.
- Header dan Navigasi: Menampilkan identitas website serta menu navigasi.
- Halaman Blog: Menampilkan daftar artikel yang tersedia.
- Halaman Artikel: Menampilkan isi artikel secara individual.
- Arsip dan Kategori: Mendukung tampilan artikel berdasarkan arsip atau kategori.
- Sidebar: Menyediakan area widget pendukung.
- Footer: Menampilkan bagian bawah halaman website.
- Kustomisasi Tampilan: Menggunakan warna pastel dan elemen dekoratif yang sesuai dengan identitas Ruang Cerita Ninis.
- Integrasi WordPress: Memanfaatkan fungsi WordPress untuk menampilkan konten dinamis.

Teknologi yang Digunakan
- HTML
- CSS
- PHP
- WordPress
- MySQL/MariaDB sebagai basis data melalui instalasi WordPress
- Laragon sebagai lingkungan pengembangan lokal

Struktur File Tema
Berikut beberapa file utama yang digunakan dalam tema Ninis:
style.css - Mengatur identitas tema dan tampilan visual website.
functions.php - Mendaftarkan fitur tema dan fungsi pendukung WordPress.
header.php - Menampilkan bagian kepala website dan navigasi.
footer.php - Menampilkan bagian footer website.
front-page.php - Mengatur tampilan halaman depan website.
index.php - Menjadi template utama untuk menampilkan konten.
archive.php - Menampilkan daftar artikel berdasarkan arsip atau kategori.
single.php - Menampilkan satu artikel secara individual.
sidebar.php - Menampilkan area sidebar dan widget.

Instalasi Tema
1. Pastikan WordPress sudah terpasang dan dapat dijalankan.
2. Unduh atau salin folder tema Ninis ke direktori wp-content/themes/.
3. Buka dashboard WordPress.
4. Pilih menu Appearance (Tampilan) → Themes (Tema).
5. Temukan tema Ninis, kemudian klik Activate (Aktifkan).
6. Buka website untuk memeriksa tampilan dan fungsi tema.
7. Tambahkan artikel, kategori, dan widget sesuai kebutuhan website.

Pengujian
Tema Ninis diperiksa melalui instalasi WordPress lokal untuk memastikan tema dapat diaktifkan dan halaman utama, daftar artikel, halaman artikel, arsip, navigasi, sidebar, serta footer dapat ditampilkan.
Pengujian responsivitas pada berbagai ukuran perangkat perlu dilakukan untuk memastikan tampilan tetap nyaman digunakan pada desktop maupun perangkat seluler.
