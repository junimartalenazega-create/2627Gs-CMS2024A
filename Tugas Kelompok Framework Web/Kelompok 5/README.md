# Eksplorasi CodeIgniter 4 — Kelompok 5

## Deskripsi

Dokumentasi ini berisi hasil eksplorasi dan demonstrasi sederhana CodeIgniter 4 untuk memenuhi tugas mata kuliah Pemrograman CMS.

Eksplorasi dilakukan dengan menggunakan Laragon sebagai lingkungan server lokal, PHP, Composer, Visual Studio Code, dan browser.

## Tujuan

1. Mengenali struktur folder utama CodeIgniter 4.
2. Memahami fungsi routing, controller, dan view.
3. Mempraktikkan pembuatan halaman sederhana menggunakan CodeIgniter 4.
4. Mendokumentasikan kode dan hasil pengujian aplikasi lokal.

## Teknologi yang Digunakan

- CodeIgniter 4 versi 4.6.5
- PHP 8.1.10
- Composer 2.4.1
- Laragon
- Visual Studio Code

## Hasil Demonstrasi

Demonstrasi dilakukan dengan membuat halaman `/eksplorasi`.

Route mengarahkan permintaan ke controller `Eksplorasi`. Controller kemudian memanggil view `eksplorasi.php` untuk menampilkan halaman pada browser.

Alur demonstrasi:

**Browser → Route → Controller → View → Halaman ditampilkan**

Halaman demonstrasi berhasil dijalankan melalui server lokal CodeIgniter 4.

## Isi Dokumentasi

- `Dokumentasi/`: screenshot struktur folder, kode, dan hasil demonstrasi.
- `Struktur/`: penjelasan fungsi folder utama CodeIgniter 4.
- `Kode/`: potongan kode yang digunakan dalam demonstrasi.

## Kesimpulan

Melalui eksplorasi ini, diperoleh pemahaman dasar mengenai struktur proyek CodeIgniter 4 serta hubungan routing, controller, dan view dalam proses menampilkan halaman web.
