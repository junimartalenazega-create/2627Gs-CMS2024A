## 2. Pertanyaan Diskusi

5. Mengapa demonstrasi kelompok tidak membutuhkan database?
6. Apa pertimbangan dalam memilih framework untuk sebuah proyek?

## Jawaban
1. Web framework mempermudah dan mempercepat pengembangan website karena menyediakan struktur program, pustaka, serta fitur yang dapat digunakan kembali.  Framework juga membantu pengembang mengatur routing, meningkatkan keamanan, dan mempermudah pemeliharaan kode.
2. Pengembangan web tanpa framework mengharuskan pengembang membuat banyak fungsi dan struktur secara mandiri. Sebaliknya, framework menyediakan pola kerja dan    fitur siap pakai sehingga kode lebih terorganisasi. Namun, penggunaan framework juga memerlukan waktu untuk mempelajari aturan dan struktur yang digunakan.
3. Routing menentukan fungsi atau controller yang harus dijalankan ketika pengguna mengakses URL tertentu. Contohnya, URL /mahasiswa dapat diarahkan ke MahasiswaController untuk menampilkan daftar mahasiswa. Dengan demikian, setiap permintaan pengguna dapat diproses sesuai tujuan dan menghasilkan respons yang tepat.
4. Model: Mengelola data dan aturan yang berkaitan dengan data aplikasi.
   View: Menampilkan informasi kepada pengguna melalui antarmuka website.
   Controller: Menerima dan memproses permintaan pengguna, menghubungkan kebutuhan data dengan Model, lalu menentukan respons yang akan ditampilkan melalui View.
5. Demonstrasi kelompok tidak membutuhkan database apabila tujuannya hanya menunjukkan cara kerja routing, controller, dan view. Data dapat menggunakan teks statis atau data sementara yang ditulis langsung di dalam program. Namun, jika demonstrasi memerlukan penyimpanan permanen, pencarian data, atau pengelolaan data pengguna, database akan diperlukan.
6. Beberapa pertimbangan penting adalah kebutuhan dan skala proyek, bahasa pemrograman yang dikuasai, kelengkapan fitur, keamanan, dokumentasi, dukungan komunitas, kemudahan pemeliharaan, serta biaya pengembangan dan hosting. Framework sebaiknya dipilih berdasarkan kebutuhan proyek, bukan hanya karena populer.
