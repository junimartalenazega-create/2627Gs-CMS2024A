# Konsep Web Framework

## 1. Pengertian Web Framework
Web framework adalah kerangka kerja perangkat lunak yang menyediakan struktur, komponen, pustaka, dan fungsi siap pakai untuk membantu pengembang membangun aplikasi web secara lebih terorganisasi. Kerangka kerja mempermudah pekerjaan umum seperti pengaturan alamat halaman , pemrosesan permintaan pengguna (penanganan permintaan ), validasi data, autentikasi, dan komunikasi dengan dasar data. Dengan menggunakan kerangka kerja, pengembang tidak perlu membuat semua fungsi dasar dari awal sehingga dapat lebih berfokus pada kebutuhan utama aplikasi.

## 2. Manfaat Web Framework
Manfaat utama web kerangka kerja adalah membantu mempercepat proses pengembangan aplikasi, meningkatkan konsistensi struktur kode, dan mempermudah pemeliharaan sistem. Kerangka kerja menyediakan fungsi dan komponen yang dapat digunakan kembali sehingga pengembang tidak perlu menulis kode yang sama berulang kali. Selain itu itu, struktur proyek yang telah ditentukan dapat membantu anggota tim memahami dan mengembangkan kode secara bersama-sama. Beberapa kerangka kerja juga menyediakan fitur validasi, Pengujian, pengelolaan Kesalahan, dan mekanisme keamanan yang dapat membantu proses Pengembangan. Sebagai contoh, Laravel menyediakan fasilitas untuk mengatur Rute, memvalidasi data, dan berinteraksi dengan dasar data, sedangkan Django menyediakan berbagai komponen bawaan untuk membangun aplikasi jaring. Dengan demikian, kerangka kerja dapat membantu pengembang bekerja secara lebih Terarah, terutama ketika aplikasi memiliki banyak fitur dan membutuhkan pengembangan berkelanjutan

## 3. Pengembangan dengan dan tanpa Framework
A.Pengembangan dengan  Kerangka Kerja
Pengembangan web menggunakan framework merupakan pendekatan yang memanfaatkan struktur dan fungsi yang telah disediakan oleh suatu kerangka kerja. pengembang mengikuti pola pengorganisasian kode yang ditetapkan kerangka kerja agar aplikasi lebih terstruktur dan mudah Dikembangkan. Kerangka kerja dapat membantu mengatur rute Halaman, memproses permintaan pengguna, memvalidasi masukan, serta menghubungkan aplikasi dengan dasar data. Pada bagian frontend, kerangka kerja dapat membantu membangun antarmuka menggunakan komponen yang dapat digunakan kembali. Sebagai contoh, ketika membuat situs web perpustakaan menggunakan Laravel, pengembang dapat memanfaatkan fitur penghalaan, validasi, dan pengelolaan data untuk membangun sistem peminjaman buku. pengembang tetap perlu membuat aturan khusus, seperti batas waktu peminjaman dan perhitungan denda, tetapi tidak harus membangun seluruh mekanisme dasar dari awal. Haniefardy et Al. (2019), melalui artikel Tinjauan literatur sistematis tentang penggunaan kerangka kerja dalam pengembangan web, membahas peran kerangka kerja dalam proses pembuatan aplikasi jaring. Dengan demikian, kerangka kerja dapat membantu mengatur proses pengembangan, tetapi efektivitasnya tetap bergantung pada kebutuhan aplikasi dan penerapannya oleh Pengembang. Sumber: Haniefardy et Al. (2019)
B.Pengembangan tanpa  kerangka kerja
Pengembangan web tanpa framework adalah pendekatan yang menggunakan teknologi dasar seperti HTML, CSS, dan JavaScript secara langsung untuk membangun halaman dan interaksi pengguna. Apabila aplikasi membutuhkan backend, pengembang juga dapat menggunakan bahasa pemrograman sisi server dan pustaka yang dipilih sendiri tanpa menggunakan framework lengkap. Pendekatan ini memberikan kebebasan dalam menentukan struktur proyek dan cara kerja aplikasi. Pengembangan tanpa framework cocok untuk website sederhana, halaman profil, atau proyek pembelajaran yang bertujuan memahami dasar-dasar pemrograman jaring. Namun, ketika aplikasi semakin kompleks, pengembang mungkin perlu menulis lebih banyak kode untuk mengatur navigasi, validasi, pemrosesan data, dan struktur program. Sebagai contoh, dalam situs web perpustakaan tanpa kerangka kerja, pengembang perlu merancang sendiri mekanisme pengelolaan data buku, login pengguna, dan transaksi peminjaman sesuai teknologi yang digunakan. Pendekatan ini tidak selalu lebih buruk daripada penggunaan kerangka kerja, tetapi membutuhkan perencanaan dan kedisiplinan dalam penulisan kode agar aplikasi tetap aman serta mudah dipelihara. MDN menjelaskan bahwa kerangka kerja bagian depan tidak selalu diperlukan, khususnya untuk proyek yang hanya memiliki sedikit halaman dan interaktivitas terbatas
C.Perbandingan antara pengembangan dengan dan tanpa  kerangka kerja
Perbedaan utama pengembangan web menggunakan framework dan tanpa kerangka kerja terletak pada struktur, ketersediaan fungsi, fleksibilitas, serta jumlah pekerjaan yang perlu dilakukan sendiri oleh Pengembang. Penggunaan kerangka kerja menyediakan pola dan komponen yang dapat membantu mempercepat implementasi fungsi umum, menjaga konsistensi kode, serta mempermudah pengembangan aplikasi yang memiliki banyak Fitur. Sebaliknya, pengembangan tanpa kerangka kerja memberikan kebebasan lebih besar dalam menentukan struktur dan implementasi, tetapi pengembang mungkin harus membuat lebih banyak mekanisme secara Mandiri. Dari segi pembelajaran, penggunaan kerangka kerja membutuhkan pemahaman terhadap teknologi dasar sekaligus aturan kerangka kerja, sedangkan pengembangan tanpa kerangka kerja membantu pengguna mempelajari teknologi dasar secara langsung. Artikel Haniefardy et Al. (2019) membahas penggunaan kerangka kerja dalam proses pengembangan web melalui Tinjauan literatur penelitian terdahulu. Berdasarkan pertimbangan Tersebut, tidak ada satu pendekatan yang selalu memutar baik untuk semua Proyek. Kerangka kerja lebih layak dipertimbangkan ketika aplikasi membutuhkan banyak fitur dan pengembangan berkelanjutan, sedangkan pendekatan tanpa kerangka kerja dapat digunakan untuk proyek sederhana yang kebutuhan fungsionalnya terbatas
## 4. Contoh Web Framework frontend dan backend
1. Kerangka Frontend 
Frontend merupakan bagian aplikasi web yang berinteraksi langsung dengan pengguna, seperti halaman login, menu navigasi, formulir, tombol, dan tabel informasi. Bagian ini umumnya dijalankan melalui browser dan menggunakan HTML, CSS, serta JavaScript. Framework atau pustaka frontend membantu pengembang mengatur komponen antarmuka, memperbarui tampilan berdasarkan perubahan data, dan membangun interaksi pengguna secara lebih terorganisasi. Contoh teknologi yang digunakan pada bagian frontend adalah Angular, Vue.js, dan Bereaksi. bersudut merupakan kerangka kerja berbasis TypeScript yang menyediakan struktur untuk membangun aplikasi web, sedangkan Vue.js membantu pengembang membuat antarmuka berbasis komponen dengan pendekatan yang dapat diterapkan secara bertahap. bereaksi adalah pustaka JavaScript untuk membangun antarmuka pengguna, bukan kerangka kerja lengkap secara teknis, tetapi dapat digunakan bersama perangkat tambahan untuk membangun aplikasi jaring. Sebagai contoh, teknologi tersebut dapat digunakan untuk membuat halaman pencarian abstrak jurnal yang memiliki kotak Pencarian, daftar hasil, dan halaman detail artikel.
2. Kerangka Backend 
Backend merupakan bagian aplikasi web yang bertugas menangani logika bisnis, memproses permintaan pengguna, mengelola autentikasi, dan berkomunikasi dengan basis data. bagian ini biasanya berjalan pada server dan menyediakan data atau layanan yang dibutuhkan frontend. Kerangka kerja backend membantu pengembang mengatur rute Permintaan, memvalidasi data, serta menyusun proses aplikasi agar lebih terstruktur. contoh kerangka kerja backend adalah Laravel, Django, dan Express.js. Laravel merupakan kerangka kerja berbasis PHP yang menyediakan berbagai fasilitas untuk membangun aplikasi web, sedangkan Django adalah kerangka kerja berbasis ular piton yang menyediakan komponen bawaan untuk mendukung pengembangan aplikasi. Express.js merupakan kerangka kerja minimalis untuk Node.js yang membantu pengembang mengatur rute dan middleware dalam pemrosesan permintaan HTTP. Sebagai contoh, dalam situs web pencarian jurnal, backend menerima kata kunci dari pengguna, memproses pencarian ke dasar data, kemudian mengirimkan hasil yang sesuai kepada frontend.
3. Frontend dan backend bekerja sama untuk membentuk aplikasi web yang dapat digunakan secara lengkap. Frontend bertanggung jawab menampilkan informasi dan menerima interaksi pengguna, sedangkan backend memproses permintaan, menjalankan logika bisnis, dan mengelola data. Sebagai contoh, dalam sistem pencarian abstrak jurnal ilmiah, frontend dapat dibuat menggunakan Vue.js atau React untuk menampilkan kolom pencarian dan daftar hasil. Ketika pengguna memasukkan kata kunci, frontend mengirimkan permintaan kepada backend yang dibangun menggunakan Laravel, Django, atau Express.js. Backend kemudian memproses kata kunci, mencari data yang relevan pada basis data, dan mengirimkan hasilnya kembali dalam format yang dapat dibaca frontend. Setelah menerima respons tersebut, frontend menampilkan judul jurnal, abstrak, dan informasi lainnya kepada pengguna. Integrasi kedua bagian ini memungkinkan aplikasi dikembangkan secara lebih terorganisasi karena antarmuka dan pemrosesan data dapat dikelola secara terpisah. Namun, komunikasi keduanya tetap perlu dirancang dengan baik, termasuk validasi masukan, pengelolaan kesalahan, dan perlindungan data pengguna

## 5. Keterbatasan Web Framework
Meskipun web framework memiliki berbagai manfaat dalam pengembangan aplikasi web, penggunaannya juga memiliki beberapa keterbatasan. Pengembang perlu mempelajari struktur, aturan, konfigurasi, dan cara kerja framework sebelum dapat menggunakannya secara efektif. Selain itu, penggunaan framework tertentu dapat menambah kompleksitas aplikasi, ukuran dependensi, serta kebutuhan pemeliharaan, terutama jika diterapkan pada proyek sederhana yang sebenarnya tidak membutuhkan banyak fitur.
